# Generic Linked List & CSV · Java

Java data-structure practice combining a generic singly linked list, OpenCSV input and JUnit tests.

**JAVA · LINKED-LIST · GENERICS**

## What is included

- Add, append and search generic values.
- Explore list size, empty-state and index operations.
- Read sample CSV input and exercise linked-list behavior with tests.

| Location | Purpose |
| --- | --- |
| [LinkList.java](src/main/java/com/singly_link_list/LinkList.java) | Generic linked list |
| [CSVFileReader.java](src/main/java/com/singly_link_list/CSVFileReader.java) | CSV example |
| [src/test](src/test) | JUnit tests and fixtures |

## Getting started

Use a JDK compatible with the included Gradle wrapper.

```bash
bash gradlew test
```

Windows: `gradlew.bat test`.

## Project status

Historical learning exercise. The tests describe the implementation's current semantics; review them before treating it as a general-purpose collection.

Setup commands are documented from the repository structure; execution has not been revalidated as part of this presentation update.
